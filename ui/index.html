Suelta para añadir a la colección

Organizar por estilo

1 · Clasificar

Cabina pregunta a Claude, la IA de Anthropic, el estilo de cada pista a partir del artista, el título, las etiquetas, el BPM y el tono. El audio no sale de tu Mac.

Créala en console.anthropic.com → API Keys. Se guarda solo en este Mac. Coste orientativo: entre 1 y 2 $ por cada 1.000 pistas.

2 · Crear carpetas

Ninguna carpeta elegida

Cada carpeta lleva una lista .m3u8 con sus pistas. En Rekordbox: Archivo → Importar → Lista de reproducción.

Generar loop

Describe un sonido y la IA crea un loop nuevo a tu tempo. Cabina lo guarda, lo analiza y lo añade a la colección; si eliges un plato, lo carga ahí con el loop ya puesto.

Servidor

Necesitas tener en marcha OBSIDIAN Neural GPU Server (github.com/innermost47/obsidian-neural-gpu-server) en este Mac con Apple Silicon o en otro ordenador con GPU NVIDIA de tu red.
